# Launcher

Área reservada para um launcher C#/.NET futuro.

Nenhum executável ou projeto foi criado nesta sprint. O launcher futuro exigirá
projeto próprio de segurança, atualização assinada, integridade de arquivos,
recuperação de falhas e origem confiável dos pacotes.

Executáveis proprietários do cliente e binários baixados manualmente não serão
versionados aqui.
