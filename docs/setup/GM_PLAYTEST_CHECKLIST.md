## Fluxo sugerido

1. `//admin` abre.
2. Criar Adena e uma arma (78 ou 79).
3. Equipar e confirmar status/P.Atk.
4. Teleportar para Giran (painel teleport).
5. Alt+G responde.
6. Voltar a Talking Island / ponto seguro.
7. Não usar IDs de Dynasty/HF — devem falhar com “doesn't exist”.

Com XP 500x, farmar um mob deve subir a barra bem mais rápido que retail.
Drop de set/armor deve continuar raro (multiplicadores de drop em `1`).
