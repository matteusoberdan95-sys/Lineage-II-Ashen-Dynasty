# Web

Área reservada para componentes futuros em ASP.NET Core:

- `api/`;
- `portal/`;
- `admin/`.

Nenhum projeto foi criado nesta sprint. APIs de conta, ranking e administração só
serão desenhadas depois que a baseline Java local estiver funcional e persistente.

Os componentes web não deverão armazenar senha em texto puro, compartilhar
credenciais administrativas nem expor comandos GM diretamente.
